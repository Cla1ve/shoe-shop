# Магазин обуви

Проект по МДК 04.01. Система для компании по продаже обуви: база данных (SQLite), сервер на Python и веб-страница. Клиент выбирает обувь и оформляет заказ, менеджер и администратор работают с заказами.

Маматисаков Элмурат, 4ИСП9-45.

## Технологии

- Python 3 (только встроенные модули: `http.server`, `sqlite3`, `zipfile`, `json`)
- SQLite
- JavaScript без библиотек (`static/index.html`, `app.js`, `style.css`)
- Git

Писал под Python 3.8. Запускал на Windows 11 (Python 3.12), на ROSA Linux не пробовал.

## Как запустить

```
python3 create_db.py
python3 import_data.py
python3 server.py
```

Потом открыть http://localhost:8000.

Если не хочется импортировать из Excel, базу можно развернуть из дампа: `sqlite3 shop.db < dump.sql`.

## Что есть

- каталог: категория, поиск, сортировка по цене (работают вместе);
- скидка 25%, если на модель не было заказов в прошлом месяце;
- на складе «много» (больше 5 пар) или «мало», остаток 3 пары и меньше подсвечен красным;
- карточка товара с размерами и остатками, корзина, оформление заказа (остатки уменьшаются);
- менеджер и администратор: кнопка «Заказы», список заказов и состав, добавление заказа вручную;
- администратор: изменить дату заказа и удалить позиции (товар возвращается на склад).

## API

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/api/login?login=` | вход по логину |
| GET | `/api/categories` | категории |
| GET | `/api/products?category=&search=&sort=` | каталог |
| GET | `/api/product?id=` | карточка товара с размерами |
| POST | `/api/order/create` | создать заказ |
| GET | `/api/orders` | список заказов (менеджер, админ) |
| GET | `/api/order?id=` | состав заказа (менеджер, админ) |
| POST | `/api/order/update` | изменить заказ (админ) |
| GET | `/api/users` | список пользователей (менеджер, админ) |

После входа браузер отправляет логин в заголовке `X-Login`, а роль сервер берёт из базы.
