# Магазин обуви

Учебный проект по МДК 04.01: веб-приложение для компании по продаже обуви.

## Что умеет страница

- вход по логину (пароль не нужен);
- каталог товаров с фильтром по категории, поиском и сортировкой по цене;
- карточка товара: размеры, остатки, добавление в корзину;
- корзина и оформление заказа.

## Как открыть

Запустить сервер и открыть в браузере http://localhost:8000

Страница лежит в папке `static`: `index.html`, `app.js`, `style.css`. Написана на чистом JavaScript без библиотек.
